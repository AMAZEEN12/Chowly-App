# Chowly image sources

Chowly uses real food/drink photography in the customer-facing UI. Images are loaded from Wikimedia Commons using its `Special:FilePath` redirect so filenames remain readable and the browser receives the actual image file.

Selected sources include:
- Nigerian Jollof Rice with chicken — Wikimedia Commons, CC BY-SA 4.0
- Grilled chicken meat — Wikimedia Commons, CC0
- Guinness Malta — Wikimedia Commons
- A glass of Chapman — Wikimedia Commons
- Pounded yam and Egusi soup — Wikimedia Commons
- Zobo drink — Wikimedia Commons, CC BY-SA 4.0
- Nigerian home made suya and sliced onions — Wikimedia Commons
- Fresh Palm Wine — Wikimedia Commons
- Nigerian prepared Pepper-Soup — Wikimedia Commons
- Grilled fish in Northern Nigeria — Wikimedia Commons
- A plastic bottle water — Wikimedia Commons
- Assorted Mocktails — Wikimedia Commons

The application keeps local SVG fallbacks for resilience if a remote image host is unavailable. Menu items also honour an image URL supplied by the restaurant database before using the curated image map.
